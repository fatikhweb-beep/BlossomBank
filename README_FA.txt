Raikou Offline PWA

برای انتشار در GitHub Pages:
1) تمام محتویات این ZIP را در ریشه مخزن GitHub بارگذاری کنید (خود فایل‌ها، نه پوشه والد).
2) در Settings > Pages، شاخه اصلی (main) و پوشه /(root) را انتخاب و Save کنید.
3) آدرس GitHub Pages را با Chrome اندروید باز کنید و از منوی مرورگر «افزودن به صفحه اصلی» یا «نصب برنامه» را بزنید.

پس از اولین بارگذاری موفق، فایل اصلی و آیکون‌ها در Service Worker ذخیره می‌شوند و برنامه برای اجرای آفلاین در دسترس خواهد بود. برای نصب اولیه و ذخیره فایل‌ها، اینترنت لازم است.
